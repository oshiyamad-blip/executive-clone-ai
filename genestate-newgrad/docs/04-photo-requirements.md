# 04. 必要写真リスト（撮影指示書）

採用トップ `/newgrad/` に必要な写真は **全18カット**。
撮影の優先順位をつけてあるので、**A群だけ先に撮れば公開できる**構成にしている。

写真IDは `theme/inc/newgrad-photos.php` と対応している。

---

## 0. 入れ方（撮影後の作業）

ファイル名を**写真IDそのもの**にして、子テーマの `assets/img/` に置くだけ。

```
wp-content/themes/（子テーマ）/assets/img/
    P-01.jpg
    P-02.jpg
    P-03.jpg
    ...
```

- 対応拡張子：`.webp` → `.jpg` → `.jpeg` → `.png` の順に探索する（`.webp` 推奨。軽い）
- ファイルが無い間は、画面上に「どんな写真がここに入るか」を書いたプレースホルダが出る
- **ファイルを置いた瞬間に反映される。** WordPress の管理画面での操作は不要

---

## 1. 全カット共通の指定

| 項目 | 指定 |
| --- | --- |
| 形式 | WebP または JPEG（sRGB） |
| 品質 | JPEG 品質80前後。1カットあたり **300KB以下** を目安に |
| 長辺 | 2000px 程度で書き出し（それ以上は不要。ページが重くなる） |
| 色味 | **既存コーポレートサイトの写真と揃える。** 彩度・コントラストを上げすぎない |
| 加工 | 過度なレタッチ・強いフィルタは不可。誠実さがこの会社の訴求のため |
| 人物 | **顔と表情が見えること。** 後ろ姿・手元だけのカットは補助的な使用にとどめる |
| 服装 | 普段の就業時と同じ服装。**採用撮影用に全員スーツで揃えない**（実態と違うと入社後ギャップになる） |
| 表情 | 作り笑いではなく、会話・作業の途中の自然な表情。「撮られている感」を避ける |
| 明るさ | 窓際の自然光を基本に。オフィスの蛍光灯だけだと色かぶりしやすい |

### 撮影前に必ず済ませること
- ⚠️ **被写体となる全社員から、採用サイトへの掲載同意（肖像権）を書面で取得する**
- ⚠️ **背景の映り込みを確認する**：モニタ画面の顧客情報、ホワイトボードの案件名、
  書類、名札、他社ロゴ。**これが最も多い事故**。撮影時にモニタは意図的にオフか、
  差し支えない画面に切り替える
- 会議室を使う場合、予約状況ボードなどに社外秘情報が出ていないか確認

## 2. 優先度A：これが揃えば公開できる（6カット）

### P-01 ／ MV（メインビジュアル）★最重要
| | |
| --- | --- |
| 使用箇所 | ページ最上部の全画面ビジュアル |
| 向き・比率 | **横位置**。PC 16:9、モバイルでは中央付近が切り抜かれる |
| 被写体 | 社員2〜4名が自然に会話している場面。若手が中心に写ること |
| 構図 | **上部3〜4割にキャッチコピーが乗る。** 人物は画面の下半分〜中央に配置し、上部は空間を残す |
| 明るさ | 上に濃紺の半透明を重ねるため、**やや明るめに撮る**（暗いと重く沈む） |
| 避ける | 全員がカメラ目線で並んだ集合写真（採用サイトで最も既視感が強い） |
| 代案 | オフィスの窓際・エントランス・打ち合わせスペースなど、場所の広がりが出る場所で |

### P-03 ／ 代表ポートレート
| | |
| --- | --- |
| 使用箇所 | MESSAGE セクション |
| 向き・比率 | **縦位置 3:4** |
| 被写体 | 代表取締役 小島 大知 氏 |
| 構図 | バストアップ〜膝上。正面またはやや斜め、**視線はカメラへ** |
| 背景 | オフィス内。背景は軽くぼかす |
| 表情 | 硬すぎない。**「先輩がいない」と正直に語る文章の隣に置く写真**なので、威圧感より誠実さ |

### P-09 ／ 研修風景 ★訴求の核
| | |
| --- | --- |
| 使用箇所 | GROWTH セクション（横長の帯） |
| 向き・比率 | **横位置。上下がかなり切られる（21:9）ので、被写体は水平方向に配置** |
| 被写体 | 研修中の様子。講師が教えている場面、または受講者が画面に向かっている場面 |
| 補足 | オンライン研修が中心なら、**PC画面越しに講師と話している自宅／オフィスの様子**でよい。実態と違う「教室で一斉授業」の絵をつくらない |
| 重要 | このページで学生が最も見たい写真。**「充実した研修」の唯一の視覚的証拠**になる |

### P-14 ／ オフィス（引き）
| | |
| --- | --- |
| 使用箇所 | CULTURE ギャラリー左端 |
| 向き・比率 | 横位置 4:3 |
| 被写体 | 新宿アイランドタワー5階のオフィス内観 |
| 構図 | 人が数名入っている引きのカット。無人だと寒々しく見える |
| 補足 | ビルの外観カットも1枚あると `/newgrad/culture/` で使える |

### P-18 ／ 最終CTA背景
| | |
| --- | --- |
| 使用箇所 | ページ最下部「一期生を、募集します。」の背景 |
| 向き・比率 | 横位置・引き |
| 構図 | **上に濃紺を78%の濃さで重ねる**ため、細部は見えなくなる。明るく、被写体が中央に寄っていないカット |
| 代案 | **P-01 の別カットで代用可**。専用に撮らなくてもよい |

### P-02 ／ 「育てる」を象徴するカット
| | |
| --- | --- |
| 使用箇所 | INTRODUCTION セクション |
| 向き・比率 | 横位置 4:3 |
| 被写体 | **先輩が若手に教えている場面。** PCの画面を一緒に見ながら、または資料を指しながら |
| 構図 | 2名。**2人の距離が近いこと**が重要（この会社の一番の訴求を1枚で表す） |
| 避ける | 上司が立って部下を見下ろす構図 |

## 3. 優先度B：事業・職種の理解に必要（5カット）

### P-04 ／ IT事業
横位置 16:10。エンジニアがPCに向かっている場面。手元とディスプレイ、人物の表情が入る画角。
⚠️ **モニタに実案件のコードや顧客名が映らないこと。**

### P-05 ／ 人材事業
横位置 16:10。面談テーブルで2名が向き合って話している場面。
コーディネーターが相手の話を聞いている表情が理想。

### P-06 ／ BPO事業
横位置 16:10。事務・オペレーション業務の場面。ヘッドセット着用のカットも可。
⚠️ **書類・モニタの個人情報の映り込みに特に注意。**

### P-07 ／ 人材コーディネーターの仕事
横位置 16:9。P-05 と似るが、**こちらは「はたらいている人」が主役**。
コーディネーター側の表情がはっきり見える角度で。

### P-08 ／ エンジニアの仕事
横位置 16:9。若手エンジニアがモニタに向かっている場面。
**背中越しではなく、表情が見える角度**で（学生は「どんな顔で働いているか」を見ている）。

## 4. 優先度C：人と空気を伝える（7カット）

### P-10〜P-13 ／ 社員ポートレート 4名
| | |
| --- | --- |
| 向き・比率 | **縦位置 3:4（全員そろえる）** |
| 構図 | バストアップ。背景はオフィス。4名で**画角・明るさ・背景のトーンをそろえる**（一覧で並ぶため、バラつくと見栄えが崩れる） |
| P-10 | 未経験から入社したエンジニア社員 |
| P-11 | 人材コーディネーター／営業職の社員 |
| P-12 | 人事・新卒採用の立ち上げ担当者 |
| P-13 | 現場のリーダー・管理職 |

> 💡 個別インタビューページ `/newgrad/people/{slug}/` では、**1名につき追加で
> 「業務中カット2枚」**が必要になります。ポートレート撮影と同じ日に、
> その人の実際の仕事の場面も押さえておくと二度手間になりません。

### P-15 ／ 執務スペース
横位置 4:3。実際に人が働いている執務席。P-14 より寄りで。

### P-16 ／ 休憩・談笑シーン
横位置 4:3。**このページで唯一「空気感」を伝えるカット。**
休憩スペースやオフィスの一角で自然に笑っている場面。演出しすぎない。

### P-17 ／ 社内イベント
横位置 4:3。懇親会・表彰・勉強会など。
**過去の写真の流用で構わない**（新たに撮る必要はない）。

## 5. 撮影進行の提案（1日で撮り切る場合）

| 時間帯 | 内容 | 備考 |
| --- | --- | --- |
| 午前 | P-14 / P-15（オフィス引き・執務） | 人が多い時間帯のほうが自然 |
| 午前 | P-04 / P-05 / P-06（3事業） | 各事業の担当者に協力を依頼 |
| 昼 | P-16（休憩・談笑） | 実際の休憩時間に |
| 午後 | P-10〜P-13（ポートレート4名） | **同じ場所・同じ光で連続して撮る**。4名分まとめて |
| 午後 | P-07 / P-08（職種カット） | ポートレート撮影者にそのまま業務シーンも |
| 午後 | P-03（代表） | 代表のスケジュールを最優先で押さえる |
| 夕方 | P-01 / P-18（MV） | **人数を集める必要があるため、終業前が集めやすい** |
| 別日 | P-09（研修） | 研修実施日に合わせる。**日程が別になる可能性が高い** |
| 不要 | P-17 | 既存写真から選定 |

### 撮影を依頼する場合の伝え方
> 「採用サイト用。18カット。うち縦位置のポートレートが5枚（代表含む）、
> 残りは横位置。web用のみでプリント不要。長辺2000pxのsRGBで納品。
> 全員の顔が見えること、演出しすぎないことを重視。」

## 6. 写真が間に合わない場合

**写真が無くても公開はできる。** プレースホルダが表示されるだけで、レイアウトは崩れない。

ただし以下だけは、**代替を用意してでも初回公開時に入れることを推奨する**：

| ID | 理由 |
| --- | --- |
| P-01（MV） | ここが空だと、ページ全体の第一印象が成立しない |
| P-03（代表） | 顔の見えない代表メッセージは、一期生の不安に対して効かない |
| P-09（研修） | 育成訴求の唯一の視覚的証拠。無いと「言っているだけ」に見える |

⚠️ **ストックフォト（素材サイトの写真）で人物カットを代用するのは避けてください。**
学生は複数社の採用サイトを横断して見るため、同じ素材写真に別の会社で遭遇します。
その瞬間、そのページに書かれた文章全体の信頼が失われます。
オフィスや街並みなどの**人物が写っていないカット**であれば、一時的な代用は許容範囲です。
