# 05. 社内で確定が必要な情報リスト

テンプレートには暫定値を入れてあるが、**以下はこちらでは決められない／裏が取れない項目**。
確認が済んだ項目から `theme/inc/newgrad-content.php` を書き換え、
その項目の `'todo' => true,` の行を削除する。

すべての `todo` が消えたら、子テーマの `functions.php` で
`define( 'NG_DRAFT_MODE', false );` を有効にして公開できる状態になる。

> 現在の未確認件数は、下書きモード中のページ上部のバーに表示される。

## 掲載してはいけないもの（再掲）

- ❌ **新卒の離職率・定着率**（一期生のため、まだ実績が存在しない）
- ❌ 中途社員の声を、新卒社員の声のように見せる表現
- ❌ 実在しない制度・福利厚生
- ❌ 「必ず」「全員が」といった断定表現（研修修了・配属・資格取得について）

4. 写真撮影（`docs/04-photo-requirements.md` の優先度A・6カット）
