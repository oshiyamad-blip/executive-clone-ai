# 07. 採用サイトのトンマナ — 方針と参考サイト

「採用サイトだけコーポレートと調子を変える」という選択について、
判断材料と、用意した5案の狙いをまとめたもの。

---

## 1. 実際、別トンマナにしている会社は多い

同一ドメインで比べられる例として、**サイボウズ**を確認した。
コーポレートと採用で、読み込んでいる書体そのものが違う。

| | URL | 読み込んでいる欧文書体 |
| --- | --- | --- |
| コーポレート | `cybozu.co.jp` | Lato |
| 採用 | `cybozu.co.jp/recruit/` | Montserrat + Roboto（＋Noto Sans JP） |

> 2026-08-31 に各ページのHTMLを取得して確認した実測値。

書体を変えるということは、**トンマナを意図的に切り離している**ということ。
色や余白だけでなく、文字の骨格から作り分けている会社がある。

### なぜ変えるのか

- **読み手が違う**。コーポレートは取引先・株主向けで「信頼」を出す。
  採用は学生向けで「入りたい」と思わせる必要がある
- **比較される相手が違う**。学生は他社の採用サイトと並べて見る。
  コーポレートの静けさのままだと、印象で埋もれることがある
- **載せる情報が違う**。人・成長・空気感といった、
  コーポレートには載らない情報が主役になる

### 変えないほうがよい場合もある

- 会社の規模が大きくなく、**ブランドの認知をこれから作る**段階
- コーポレートサイトが最近リニューアルされていて、**そのトンマナ自体が資産**
- 運用の担当が同じで、**2系統を維持しきれない**

ジーンステイトは後者に近い条件がそろっている（コーポレートの意匠が
金と黒で明確に作り込まれており、初年度の立ち上げで運用体制もこれから）。
そのため **既定は「A コーポレート準拠」** にしてある。

---

## 2. 用意した5案

`preview/switcher.html` の「トンマナ」スイッチで切り替えられる。
**配色は5案とも、実サイトから採取した3色（黒・金・生成り）のまま**で、
新しい色は1色も足していない。変えているのは書体・大きさ・角の丸み・
そして色の「役割」だけ。

まだ大枠を決める段階なので、**振り幅を広く取ってある**。
A が既存サイトそのままで、E がいちばん遠い。

| | 一言で | 和文書体 | 角 |
| --- | --- | --- | --- |
| A | 既存サイトそのまま | Zen Kaku Gothic New | 片角240px |
| B | 生成りの地に白い面＋金の面 | Zen Kaku Gothic New | 四隅32px |
| C | 黒地に金 | Zen Kaku Gothic New | 片角240px |
| D | 明朝で読み物に | **Noto Serif JP** | 角なし・罫線 |
| E | 丸ゴシックで親しみ | **M PLUS Rounded 1c** | 四隅24px |

D と E は**和文書体そのものを替える**ため、印象の変化が最も大きい。
その2案を選ぶ場合は、対応する Google Fonts の読み込みが本番でも必要になる。

### A コーポレート準拠（既定）

実サイトの採取値そのまま。Marcellus（明朝）の英字が主役で、和文は
14pxの小ラベル＋金の丸。角は控えめ、影なし。

- **効く場面**：既存サイトからの流入が多い。会社の落ち着きを見せたい
- **弱点**：他社の華やかな採用サイトと並ぶと、印象で負ける可能性

### B 新卒向け・やわらかめ

**「白い紙の上に組む」のをやめ、「生成りの地に、白い面を浮かべる」に組み替えた案。**
使う色は実サイトの3色のままだが、**地と面の役割を入れ替える**ため、
ひと目で別のサイトに見える。

| 変えたこと | 理由 |
| --- | --- |
| 地を白 → 生成り。セクションは角丸32pxの白い面として浮かせる | 構成そのものを変える。ここがAとの最大の差 |
| 片角だけ240px落とす切り欠きをやめ、四隅をそろえて丸める | あの切り欠きはコーポレートの署名。採用では使わない |
| 数字セクションを黒ベタ → **金の面** | ページ内で最も目を引く場所を、暗さではなく明るさで作る |
| 欧文の明朝をやめる | 明朝は「格」を出すが、学生には硬く映る |
| 見出しの主従を戻す（和文を大きく、英字を小さな金のラベルへ） | 学生が読むのは日本語のほう |
| ボタンの罫線を olive → 金に、本文 16px → 17px | 明るさと読みやすさ |

金の丸は英字ラベルの側へ移して残してある（サイトの記号なので消さない）。
金の面に載る文字は黒。**金に白は読みにくい**ため。

- **効く場面**：明るく前向きな会社に見せたい。他社と並べても埋もれたくない
- **弱点**：コーポレートを見てから来た人には「別のサイト」に映る。
  金の面積が増えるので、金の印刷再現が必要な媒体との調整が要る

### C 新卒向け・ダーク

**黒と金だけで面を反転した案。** 地を黒、文字を生成り、金を主役の
アクセントに置く。エンジニア採用のサイトに多い方向。

- **効く場面**：一期生の「はじまり」を強く出したい。IT企業らしさを出したい
- **弱点**：写真の見え方が大きく変わる（暗い背景に載る前提の撮影が要る）。
  コーポレートとの距離が3案で最も遠い

### D 明朝・エディトリアル

**和文も明朝に替え、角を落とさず罫線で区切る案。** 読み物としての採用サイト。
「育てる」を事業にしてきたという誠実さの訴求と相性がよい。

| 変えたこと | 理由 |
| --- | --- |
| 和文を **Noto Serif JP**（明朝）に | 骨格から変わるので、印象の変化が最も大きい |
| 角丸をすべて 0 に。ボタンも矩形 | 明朝に丸い角は合わない。直線で通す |
| セクションの境目を罫線に | 片角の切り欠きをやめた代わり |
| 行間 2 → 2.1、字間を広げる | 明朝は字面が細いので、余白で読ませる |

矢印の丸だけは残してある。直線のなかで1つだけ丸があると視線が留まるため。

- **効く場面**：落ち着き・品を出したい。読ませる文章量が多い
- **弱点**：若さや勢いは出ない。学生には「堅い」と映る可能性

### E 丸ゴシック・親しみ

**丸ゴシックで警戒心を下げ、要素を大きく丸くした案。**
日本の新卒採用サイトでは定番の方向。5案でいちばん柔らかい。

| 変えたこと | 理由 |
| --- | --- |
| 和文・欧文とも **M PLUS Rounded 1c**（丸ゴシック）に | 学生向けの定番。親しみが出る |
| 角丸 8px → 24px、片角丸 240px → 48px | 全体をまるくする |
| 見出しの主従を戻す（和文を主役に） | 学生が読むのは日本語のほう |

- **効く場面**：未経験・文系の学生に広く届けたい。堅さを完全に外したい
- **弱点**：コーポレートとの距離が最も遠い。会社の落ち着きは伝わりにくい

### 見るときの観点

同業・同規模の会社を3〜5社見て、次の点をメモすると比較しやすい。

1. コーポレートサイトと**色が同じか、変えているか**
2. 第一画面が**写真主役か、言葉主役か**
3. **社員の顔**がどれくらい出ているか
4. 数字（社員数・平均年齢など）を**どう見せているか**
5. スマートフォンで見たときに**最初の画面に何が入っているか**

## 4. 決め方

1. `preview/switcher.html` で5案を切り替えて見比べる
2. 上の参考サイトを3〜5社見る
3. 決めたら、子テーマの `functions.php` に1行書く

```php
define( 'NG_TONE', 'b' );   // a=準拠 / b=生成り＋金 / c=ダーク / d=明朝 / e=丸ゴシック
```

> **D と E は書体の読み込みが増える。** 本番では選んだ案の書体だけを読めばよい。
> `tools/chrome.php` の `ng_fonts_link()` に対応表がある。

書かなければ `a`（コーポレート準拠）になる。

> **写真の撮影に影響する。** C（ダーク）を選ぶ場合、暗い背景に載る前提で
> 撮る必要があるため、`docs/04-photo-requirements.md` の指示を先に更新したい。
> **撮影の発注前に決めておきたい項目**。
