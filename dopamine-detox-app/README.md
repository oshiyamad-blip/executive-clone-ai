# ドーパミンデトックス

スマホから離れる時間をつくり、離れられなかった瞬間を残しておくための個人用アプリ。
機能は2つだけに絞ってある。

1. **デトックスセッション** — 時間を決めてスマホを置く。中断したらその理由も残す
2. **衝動ログ** — 「見たくなった」瞬間を1タップで記録し、自分のトリガーを見えるようにする

依存パッケージなし・ビルドなしの PWA。Android のホーム画面に追加すればアプリとして動き、
記録は端末の中だけに残る（サーバーに送信しない）。

## Android にインストールする

1. GitHub Pages などの **HTTPS** で公開する（下記「置き場所と公開」参照）
2. Chrome for Android でその URL を開く
3. メニュー → **アプリをインストール**（または「ホーム画面に追加」）

インストールすると全画面で立ち上がり、機内モードでも動く。

> `file://` で直接開いたり、`http://192.168.x.x` で開いた場合は Service Worker と通知が
> 使えない（ブラウザが安全なコンテキストとして扱わないため）。実機で試すなら HTTPS 必須。

## 使い方

### セッション

長さを選んで **セッションを開始**。あとは画面を伏せて待つだけ。

- 残り時間は「開始時刻 + 長さ - 現在時刻」で毎回計算している。画面ロック中でもアプリを
  閉じている間でもズレず、閉じている間に終わっていた分もアプリを開いた時点で完了になる
- **一時停止は用意していない。** 止められるデトックスは大体止まるので、選択肢は
  「最後までやる」か「中断を記録する」の2つだけにしてある
- 中断すると「何に負けたか」を聞かれ、それがそのまま衝動ログの1件（見てしまった）になる
- 終了時は 通知 / 音 / 振動 で知らせる（設定で個別にオフにできる）
- 実行中は画面が消えないようにする（Wake Lock。端末が対応していて、電池セーバー中でない場合）

### 衝動ログ

右下の **衝動を記録** から、手が伸びかけた瞬間を残す。セッション中は画面中央の
大きなボタンが同じ役割をする。

記録するのは 対象 / 強さ(1-5) / きっかけ / 結果（耐えた・見てしまった） / メモ。
すべて任意で、対象を選んで **記録する** を押すだけでも残せる。

**記録**タブで、その日の実施時間・完了本数・「耐えた/衝動」の比と、セッションと衝動を
混ぜた時系列が見られる。何時ごろ・何がきっかけで手が伸びるのかは、ここを数日ぶん
眺めると分かる。

## データ

記録は `localStorage`（キー `dopamine-detox/v1`）にだけ保存される。

**ブラウザのサイトデータを消すと記録も消える。** 設定タブから JSON で書き出せるので、
ときどき保存しておくこと。読み込みは追加（マージ）で、同じ id の記録は重複しない。

## 開発

すべて `dopamine-detox-app/` の中で実行する。

```bash
npm install        # typescript と @types/node だけ（実行時の依存はゼロ）
npm start          # http://localhost:5173 で配信
npm start -- --host  # 同じ LAN の端末から見る（SW と通知は無効になる）
npm run typecheck  # JSDoc + tsc --checkJs による型チェック
npm run icons      # assets/*.png を再生成（zlib だけで PNG を書き出している）
```

ソースは素の ES モジュールで、トランスパイルもバンドルもしない。型は JSDoc で書いて
`tsc --checkJs` で検査する。`npm run typecheck` は CI でも走る。

```
index.html          画面3つ（セッション / 記録 / 設定）とシート2つ
styles.css          白基調・無彩色。区別は濃さ・太さ・余白で付ける
sw.js               Service Worker（stale-while-revalidate）
src/store.js        状態と localStorage 永続化、書き出し／読み込み
src/session.js      セッションのドメインロジック（残り時間は常に実時刻から算出）
src/impulse.js      衝動ログ
src/alerts.js       Wake Lock / 通知 / 音 / 振動。全部「失敗しても黙って諦める」
src/dom.js          DOM とフォーマットのヘルパー
src/views/          画面ごとの描画
scripts/serve.mjs   開発用の静的サーバー
scripts/gen-icons.mjs  PNG アイコン生成
```

## 置き場所と公開

このアプリは `executive-clone-ai` リポジトリの `dopamine-detox-app/` に同居している。
GitHub Actions のワークフローはリポジトリのルートにしか置けないため、ビルド定義だけは
親リポジトリの `.github/workflows/` にある。

- `detox-pages.yml` — `main` への push で **`dopamine-detox-app/` だけを** GitHub Pages に公開する。
  `path` をこのディレクトリに限定してあるので、親リポジトリの他の内容は成果物に含まれない
- `detox-typecheck.yml` — このディレクトリが変更されたときだけ型チェックを走らせる

公開に必要な手順は2つ。

1. このディレクトリを `main` に入れる
2. リポジトリの **Settings → Pages → Source** を **GitHub Actions** にする

公開後の URL は `https://oshiyamad-blip.github.io/executive-clone-ai/` になる。
アプリ内のパスはすべて相対（`./`）なので、このようなサブパス配信でも動く。

アプリを更新したときは `sw.js` の `CACHE` の値を上げると、古いキャッシュが確実に捨てられる。

## 制限

- Android Chrome を想定している。iOS Safari でも動くはずだが、通知と Wake Lock は期待しない方がいい
- 端末をまたいだ同期はしない。移すときは JSON の書き出し／読み込みで
- **アプリを実際にブロックはしない。** これは記録と自覚のための道具で、強制力はない
